# Grama-Vaxi

## Livestock Vaccination Management System

Grama-Vaxi is an Android application developed to help farmers manage livestock vaccination records digitally. The app stores animal details, vaccination information, and sends notifications for vaccination reminders.

## Problem Statement

In many villages, farmers miss livestock vaccination schedules due to lack of proper communication and record management. This can lead to disease outbreaks and livestock loss.

Grama-Vaxi solves this problem by providing a digital vaccination management system.

## Features

- Farmer Login Screen
- Dashboard Screen
- Add Animal Details
- Vaccination Tracking
- Firebase Realtime Database Integration
- Notification Alerts
- RecyclerView Animal List

3. Connect Firebase
4. Sync Gradle files
5. Run the app on emulator or Android phone
